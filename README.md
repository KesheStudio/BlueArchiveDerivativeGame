## 1 角色相关

### 1.1 角色基础属性
- **生命值Health**：当生命值小于等于0时角色将被淘汰
- **基础防御减伤比例BaseResistance**：角色基础的免疫攻击百分比
- **护甲类型ArmorType**：角色在对应攻击下的减伤类型
- **暴击免疫率CriticalResistance**：减少对手暴击率百分比
- **基础攻击力BaseDamage**：角色无加成无暴击下的攻击值
- **攻击类型AttackType**：角色对指定角色特定护甲的加成或抵抗由此决定
- **基础暴击率CriticalRate**：在无加成的情况下角色的暴击率
- **各地形适应等级AdaptationLevel**：在各种地形战场上的加成
- **技能点Cost**：角色释放EX技能所需消耗的技能点数量
- **增益Buff**：当前角色所有的增益效果列表
- **减益DeBuff**：当前角色所有的减益效果列表
- **职业类型Occupation**：当前角色的职业类型仅用于筛选
- **定位PositioningType**：当前角色是前排或后排
- **站位Position**：当前角色所处的卡牌登场位置
- **上场状态IsEnable**：当前角色是否已进入战斗状态

### 1.2 角色技能
**基础介绍**：```每个角色都有一个主动技能(EX)，与三个被动技能(普通技能NS,被动技能PS,子技能SS)，与一个武器被动技能(WPS)，可能会有一个装备技能(GNS)，如果有载具的情况下可能会有一个连携技能(LS)```
- **EX**：角色大招需要消耗对应技能点才可释放
- **NS**：角色普通技能特定条件下自动释放
- **PS**：角色被动技能当角色入场时自动启用
- **SS**：角色子技能在特定条件下自动释放
- **WPS**：角色到达指定星级时自动触发
- **GNS**：角色装备(爱用品)技能获取角色特定装备后激活
- **LS**：所需角色同时上场且已召唤载具时触发

### 1.3 角色介绍页
**介绍页会标明角色的以下信息**
1. 角色名称
2. 角色所属学院/社团
3. 角色技能介绍
4. 角色的地形等级/前后排位置信息
5. 角色CV/画师信息
6. 角色兴趣爱好信息
7. 角色生日/年龄/身高/实装日期等信息
8. 角色个人简介/MomoTalk签名信息
9. 角色武器信息(名称/简介/图片等)

### 1.4 其他内容
- 每个角色都有至少一张立绘作为卡面
- 每个角色根据不同学院分配卡背样式
- 每个角色至少属于某个学院的某个社团(包含原创角色)
